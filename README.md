# 1830-grandin-palmyra-book-of-mormon
Markdown &amp; Plain Text extractions of the content of the 1830 edition of the Book of Mormon published by E.B. Grandin Palmyra, New York, based on the manuscript copy provided by Oliver Cowdery, which he copied from the original manuscript dictated by Joseph Smith and transcribed by Cowdery and others from April 1829 through June 1829.
