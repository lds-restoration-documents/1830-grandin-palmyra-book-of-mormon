This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

A text corpus, not software: AI-assisted transcriptions of the 1830 E. B. Grandin (Palmyra, N.Y.) first edition of the Book of Mormon, extracted from an Archive.org scan of the copy owned by the University of Pittsburgh's Darlington Memorial Library (https://archive.org/details/book-of-mormon-1830). There is no build, lint, or test tooling. The scan PDF itself is **not** in this repo; the scripts that produce the derived files are in `tools/`. The methodology and tooling are adapted from the sibling project `../1828-phinney-cooperstown-bible`.

**Status:** extraction complete: all 598 PDF pages are transcribed by Sonnet 5.5 and each has been audited once against the scan (no full human proofread), then proofread a second time, blind, against fresh renders (`tools/proofread-spec.md`; results and the comma/period rule in `transcription-notes.md` §6b). The scan is `Book-of-Mormon-1830.pdf` in the repo root (gitignored): Book of Mormon text on PDF 9–592 (printed page = PDF − 4), with front matter on 1–8 and back matter on 593–598. The derived files `book-of-mormon-1830.md`, `.txt` and `-sparse.txt` have been generated; rebuild them after any page edit. Batches were run as 16-page subagent jobs (transcribe, then audit); see `transcription-notes.md` §6.

## How the files relate

`book-of-mormon-1830-pages/page-001.md` … are the **source of truth**: one file per PDF page, named by *PDF page number*, not the printed folio. Everything else is derived from them:

- `book-of-mormon-1830.md`: all pages, main text only, joined into one file.
- `book-of-mormon-1830.txt`: the same, with all Markdown removed.
- `book-of-mormon-1830-sparse.txt`: Book of Mormon text only (books, chapters, paragraphs), no title page, preface, testimonies or other front/back matter.
- `transcription-notes.md`: method, conventions, residual-risk notes, and a per-page log of every `uncertain` / `[illegible]` / layout comment.

The derived files are generated by the scripts in `tools/`, and a fix made only in a derived file is lost on the next regeneration. After changing any page file, rebuild them (Python 3 standard library only, run from anywhere):

```
python3 tools/compile_markdown.py   # book-of-mormon-1830.md
python3 tools/make_plaintext.py     # book-of-mormon-1830.txt
python3 tools/make_sparse.py         # book-of-mormon-1830-sparse.txt  (PAGE_RANGES is set to PDF 9–592)
```

`tools/render_pages.py` (needs `pypdfium2` and `pillow`) renders scan pages into the crops used for transcription; `tools/transcription-spec.md` and `tools/audit-spec.md` are the instructions the transcribing and auditing agents follow. See `tools/README.md` for the pipeline.

## Page file format

Each page file starts `<!-- PDF page NNN -->`, then: an optional `**Header:**` running-head line (parts separated by ` | `), headings (`#` book title, `## CHAPTER X.`), and one paragraph per printed paragraph. A paragraph that continues from the previous page starts with `<!-- cont -->`; the compile script uses it to rejoin paragraphs. After a `---` rule, an optional `Footer:` line holds signature marks / catchwords. Blank pages, covers and stamps are a one-line comment. Full details are in `tools/transcription-spec.md`.

This edition differs from the Phinney Bible: **no verse numbers, no marginal notes, no reference letters**, one wide column, long paragraphs, italic chapter summaries, very sparse punctuation, the type puts a thin space before `; : ? !` which we do NOT transcribe (write none). Page-top paragraph continuations are flush-left, so look at indentation: a flush-left first line gets `<!-- cont -->`. Do not add verse numbers, modern punctuation or paragraph breaks.

## Rules when editing

- **Write what the scan shows, never what you think it should say.** Printer's errors, odd spellings, names, grammar, missing or doubled words, damaged type and wrong running heads are kept as printed. Do not "fix" them from knowledge of later editions of the Book of Mormon, the King James Bible, or the manuscripts.
- Doubtful readings stay in place with `<!-- uncertain: … -->`; unreadable text is `[illegible]`.
- Never transcribe from the OCR text alone: the page image is authoritative and the OCR is only a helper. If the image tool fails for a page, stop and report that page as failed.
- Work in batches of 16 pages, writing each file right after reading its page; skip pages whose output file already exists so interrupted runs can resume.
- Record the model that wrote each page range, and which ranges have been audited, in `transcription-notes.md` §1 (see how the Phinney repo did it). Do not claim a page was audited or proofread when it was not.
- Page files are keyed to PDF page numbers (3-digit, zero-padded). Keep the first-line page comment in sync with the filename.
